# app/ — 페이지와 API 라우트

상위 규칙: [../AGENTS.md](../AGENTS.md), UI 의도: [../INTENT.md](../INTENT.md)

## 구성

| 경로 | 역할 |
|---|---|
| `page.tsx`, `login/`, `terms/`, `privacy/` | 공개 화면 |
| `dashboard/**` | 로그인 화면. 모두 같은 셸 사용 |
| `blog/**` | 공개 아카이브(로그인 없이 열림) |
| `mcp-auth/` | MCP OAuth 인가 시 인증키 입력 화면 |
| `api/**` | 서버 진입점. 브라우저와 MCP 클라이언트가 부르는 유일한 서버 경로 |
| `.well-known/**` | OAuth 메타데이터. 외부 계약이므로 형식을 바꾸지 않음 |
| `robots.ts`, `sitemap.ts` | 공개 주소 환경 변수 기준 |

## 페이지 규칙

- 로그인 화면은 서버 컴포넌트에서 `requireAuth()`로 시작한다. 미들웨어 보호에만 기대지 않는다.
- 페이지는 데이터 조회·화면 조립만 한다. 비즈니스 로직은 `lib/`, 상호작용은 `components/`.
- 서버 컴포넌트에서 자기 앱의 `/api/*`를 HTTP로 다시 부르지 않는다. 같은 `lib/` 함수를 직접 호출한다.
- 공개 화면(`blog/**`)은 `published` 상태 데이터만 읽는다. 미리보기·비공개 열람 분기를 두지 않는다.
- 메타데이터의 사이트 주소·이름은 환경 변수에서 가져온다.

## API 라우트 규칙

처리 순서를 지킨다.

```text
1. 입력 검증 (zod)            → 실패 400 { error, code: "INVALID_INPUT" }
2. 인증 requireApiUserId()    → 실패 401 { error: "로그인이 필요합니다." }
3. 범위 workspaceIdsForUser() → 대상이 범위 밖이면 404
4. lib/* 서비스 호출
5. NextResponse.json(결과)
```

- 라우트 파일은 얇게. 한 라우트가 50줄을 넘으면 로직을 `lib/`로 옮긴다.
- 상태 코드를 명시한다: 400 입력, 401 인증, 403 승인 필요·기능 꺼짐, 404 없음/범위 밖, 409 충돌, 502 외부 서비스 오류, 503 설정 누락.
- 오류 응답은 `{ error: "한국어 한 문장", code: "UPPER_SNAKE" }`. 외부 API 원문, 스택, SQL 오류 메시지를 그대로 내보내지 않는다.
- 응답에서 암호문, 키 원문, 토큰 해시, 다른 사용자 정보를 뺀다. `select("*")`를 그대로 반환하지 않고 필요한 필드만 고른다.
- 외부로 쓰는 동작(동기화, 게시)은 요청 본문 또는 사용자 동작으로 승인이 확인된 경우에만 실행한다.
- 선택 기능 키가 없으면 503 `{ code: "..._DISABLED" }`로 답한다. 예외를 던져 500을 내지 않는다.

## MCP 라우트 (`api/mcp/**`)

- `/api/mcp`는 OAuth 액세스 토큰만 받는다. 고정 토큰·인증키 Bearer는 401.
- 도구는 OAuth 사용자의 workspace만 읽고 쓴다. principal이 없으면 아무 도구도 실행하지 않는다.
- 쓰기 도구는 `mcp:learn` scope와 `approved: true`가 모두 있어야 실행한다.
- 도구 입력은 zod로 검증하고, 결과는 비밀값 없이 JSON 텍스트로 돌려준다.
- 새 도구는 웹 API와 같은 `lib/` 함수를 호출한다. 도구 전용 로직을 라우트에 쓰지 않는다.
- OAuth 엔드포인트(`register`, `authorize`, `token`, `revoke`)와 `.well-known` 응답 형식은 MCP 클라이언트와의 계약이다. 바꿀 때는 실제 클라이언트로 연결을 다시 확인한다.

## 하지 말 것

- 브라우저 전용 API(`window`, `localStorage`)를 서버 코드에서 쓰지 않는다.
- 공급자(외부 원본)마다 최상위 메뉴·라우트를 늘리지 않는다. 원본 연결 화면 아래에 둔다.
- 관리자 전용 라우트를 만들지 않는다.
